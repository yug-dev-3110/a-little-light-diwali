# 🪔 A Little Light, Just for You

A small Diwali surprise made with code, creativity, and a little bit of light. ✨

**A Little Light, Just for You** is an interactive Diwali greeting website designed to make festival wishes more personal and memorable. Instead of sending a traditional text message, visitors can experience a beautiful animated greeting and share it with their loved ones.

## ✨ Features

- 🪔 Beautiful animated Diwali experience
- 🎨 Elegant design with festive visuals and particle effects
- 🌐 Multilingual greetings — English, Hindi, and Gujarati
- 💌 Personalized greeting links
- 📤 Share your greeting with friends and family
- 🔊 Optional sound effects
- 📱 Responsive design for mobile and desktop
- ❤️ Created with love and creativity

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- HTML5 Canvas
- Web Audio API

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd a-little-light-vercel-ready
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to experience the website.

## 🏗️ Build for Production

```bash
npm run build
```

The production-ready files will be generated inside the `dist` folder.

## 🌍 Deployment

This project can be deployed easily using [Vercel](https://vercel.com/).

1. Push your project to GitHub.
2. Import the repository into Vercel.
3. Select **Vite** as the framework.
4. Set the build command to `npm run build`.
5. Set the output directory to `dist`.
6. Click **Deploy**.

The idea was simple: make Diwali wishes feel a little more special through technology.
